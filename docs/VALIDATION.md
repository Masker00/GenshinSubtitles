# v0.1.0-beta.1 验证记录

本页记录 2026-10-28 的本版本验证；游戏内手动验收与干净电脑安装尚未完成。

## 本次实测

Windows PowerShell `5.1.19041.3930`，Python `3.15.0`（用户安装，非开发工具内置 Python），可用 OCR 为 `en-US` 和 `zh-Hans-CN`。没有在 Python 3.9 或另一台干净 Windows 电脑上实测。

| 原文返回 | 真实 ID `2545425690` 的中文问题句现在返回非空官方中文 source、配对英文、exact 和 similarity 1.0；英文 0.80–0.90 接受区间也返回完整 source |

| 配置 | 默认值、SourceLanguage 迁移、非法数值、损坏/非对象 JSON 保留且禁写；原子替换备份与文件锁失败保护通过 |

首次准备目录由公开允许清单构成，数据是重新下载得到，没有从私人迁移包恢复。后续最终源码同步只覆盖允许清单中的公开文件，保留已下载数据后再次执行设置与 UI 检查。**本机干净目录不等于干净电脑测试。**

测试中使用程序化窗口消息和合成图片；无游戏窗口的暂停路径用受控返回值验证，真实游戏最小化/还原仍需要手动确认。窗口自检图片中的洋红色是 DrawToBitmap 显示透明键的测试表示，不是实际字幕背景。

## 待手动验收

- 游戏内两种识别方向、三项语言设置、剧情连续推进与字幕清除。
- 游戏运行期间 SET 选区拖动/缩放、正常鼠标穿透、收起图标与实际系统快捷键。
- 游戏最小化/关闭/还原、不同分辨率/缩放、多屏、不同窗口模式与极长台词。
- 一台未配置开发环境的 Windows 电脑，按 README 自行安装 Python/OCR 后完整首次安装。

短句覆盖、重复台词消歧、全新匹配算法和自动数据更新没有在本次解决；不把查询和自检通过扩展为全游戏覆盖率承诺。
